# SAMU GOLD KILLER · COMMAND

Phone se gold market jaancho, phir VPS par **SAMU GOLD KILLER v1.06** EA ko START karo.

App: https://ankushchhajed7-cmd.github.io/SAMU-GOLD-KILLER-COMMAND/ (demo: `?demo=1`)

- **COMMAND** — risk ring (GREEN / YELLOW / RED), START (30/60/90 min, max 1/2/3 TP), STOP, CLOSE BUY / SELL / ALL (1.5 sec daba ke), equity, basket.
- **ANALYSIS** — pichhle 2 ghante ka M1 chart, START se pehle jaanch, agle 1 ghante ka itihaas, din bhar ka risk, news.
- **TRADES** — khule trade, EA ki halat.
- **STRATEGY** — niyam + Lab backtest.
- **SETTINGS** — GitHub token (PIN se lock), repo, alert (blink / awaaz / vibrate / notification).

Kaise juda hai: app `live` branch me `control.json` likhta hai → EA har 15 sec padhta hai → EA har 30 sec `status.json` likhta hai → app dikhata hai.

Setup: STATE.md → "Ek baar ka setup".
